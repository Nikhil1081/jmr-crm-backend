# Multi-Employee CRM Portal

## Easiest way to run

```bash
pip install -r requirements.txt
uvicorn crm_portal_single_file:app --reload
```

Open: http://127.0.0.1:8000/docs

Default admin: admin@crm.com / admin123

This version is a single-file FastAPI CRM portal supporting unlimited employees, role-based access, leads, customers, opportunities, activities, and employee performance analytics for Power BI.
